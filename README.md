# dolla-dolla-bills

A hierarchical ML/RL research system for trading a small universe of volatile,
high-growth stocks. It can rotate into a defensive safe-haven sleeve (gold, silver,
T-bills) during crashes. Only long positions (buy and sell), with realistic
execution delay and costs.

**Status:** planning. See [`docs/PLAN.md`](docs/PLAN.md) for the full design and
roadmap.

> This is a research project. Nothing here is financial advice. Real capital is
> deployed only in stages, after paper trading validates the system.
